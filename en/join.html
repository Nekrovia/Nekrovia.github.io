Guide

4 steps to get playing

1

Update DayZ to version 1.29.0

Make sure the game is updated to the required version through Steam — otherwise connecting to the server will fail.

2

Launch the DayZ launcher and search for the server

In the server browser, type Nekrovia in the search field, or use the filter with the IP address: 46.151.138.13:2306.

3

Let the required mods download automatically

The DayZ launcher will automatically download and install the mods required by the server once you click "Connect" — there's nothing to install manually.

4

Join and read the rules

After joining the server, check the notice board and the rules, then start surviving.

Having trouble connecting?

Message us on Discord — we'll help you set up the game and join the server.
